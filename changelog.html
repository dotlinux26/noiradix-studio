# NOIRADIX Studio & PixelArt v2.2.0

## Highlights

- Added frame-scoped PIX2 copy, AI prompt and import actions in the Studio cell editor. Import replaces the selected frame while preserving other cells and animation data.
- Added an explicit destination step for full PIX2 code import: replace the active project with undo available, or create a separate project tab. The current file is not written until the user saves.
- Fixed frame actions to resolve the active cell through Studio's narrow document port, and kept frame controls in one horizontally draggable row.
- Added an instructions-only AI prompt option alongside full-document context. Full-document Apply is explicitly documented as replacement, not a partial merge.
- Clarified PIX2 serialization behavior: the reference serializer may normalize drawing primitives into pixel records; PIX2 1.1 does not require this canonical form.
- Made Unity sprite asset names unique when display names repeat, while retaining display names in exported metadata.
- Limited the maintenance notice to development hosts by default; it can be explicitly enabled with `?noira-maintenance=1`.
- Reorganized the README around the user workflow and documented verified product behavior, AI context limits, and current CI checks.
- Added an offline-capable static changelog page generated from the versioned Markdown release notes. It displays their raw text without a runtime Markdown dependency, and links from both About dialogs to release history, GitHub issue templates, and Discord.
- Corrected architecture, format examples, license scope, performance-proposal status and historical test-count references.
- On workspace restore, reconnect the active project to its previously granted file handle and reconcile draft bytes against disk. Preserve the saved-content baseline so disk changes made while the app was closed still raise the external-change conflict instead of silently replacing a draft.
- Warn when a disk write succeeds but the browser cannot persist its file handle, so the user knows direct saving may need the file to be reopened after reload.
- Verify external file contents on window focus even when the filesystem timestamp is unchanged; the regular heartbeat remains timestamp-gated to avoid repeatedly reading large projects.
- Fixed TexturePacker / NOIRADIX atlas JSON preview integration, added frame geometry and image-bound validation, and bounded imported metadata, file sizes, and decoded raster allocations.

## Compatibility

- Studio and PixelArt report version 2.2.0. PIX2 remains at version 1.1, with PIX2 1.0 read compatibility retained.
- Existing full-document PIX2 import behavior remains replacement. Frame import is a separate operation and validates a one-frame document before replacing the active frame.
- The serializer's canonical pixel output is an implementation choice, not a required PIX2 1.1 representation.

## Verification

- `node tests/check-readme-test-count.cjs` — passed (22 Node regression suites).
- `node tests/run-all.cjs --syntax` — passed (36 production JavaScript files).
- `node tests/run-all.cjs` — passed (22 Node regression suites).
- `node tests/benchmark-performance.js` — passed all 8 gates on the documented fixtures; observed maxima were under 16 ms in this run.
- `node tests/run-all.cjs --browser` — passed all 6 browser suites in Chrome 157 for Studio and PixelArt, including atlas JSON import, changelog generation, offline navigation, responsive layout, and feedback links.
- `git diff --check` — passed.
- The maintainer reports a successful manual Unity import check. Unity Editor is not available in automated CI, so this release does not claim compatibility across untested Unity versions.

## Limits and future work

- AI context-window and output limits depend on the selected provider and model; consult current provider documentation. Frame-scoped prompts reduce the supplied project context but cannot guarantee that a model will return valid PIX2.
- An MCP adapter for bounded frame/range reads and validated patches is a future direction and is not included in this release.
- Large-canvas typed-array storage remains a proposal; current supported workload and performance should be judged from the maintained tests and benchmarks, not historical estimates.

# NOIRADIX Studio & PixelArt 2.1.0

This release stabilizes the shared editor and the PIX2 1.1 reference implementation. The file header stays `@pix2 1.1`, and both editors continue to read PIX2 1.0.

- Grid Overview can zoom below 1×. Fit and Shift+Space fit the sprite sheet with its grid labels and spacing. The Grid backing canvas is capped at 4096 pixels per side.
- Studio and PixelArt share tools, document tabs, Layers, raster transforms, viewport rendering, adaptive rulers and browser workspace storage. Reload restores finished edits and open tabs. IndexedDB backs up workspaces when localStorage cannot store them.
- Layers show the frontmost sibling first. Drag up to bring a node forward. Use Alt+double-click in Region Select to cycle through overlapping Regions in the active Layer. A Group resize that would erase an entire populated Region is cancelled.
- The compiler preserves mixed Group/Region order across save and reload, supports inherited Layer/Group/Region opacity, and diagnoses malformed opacity, parent cycles and excessive Group depth. Ink scales pixel alpha at paint time. Modular export and flattening share the same compositor.

Automated checks include Node conformance, security and round-trip tests, plus Chromium editor and workspace tests with a dense 512×512 artwork, a 4×4 sheet of 512×512 frames, legacy conversion and quota fallback. Browser drafts preserve finished edits. Native multi-file handles, undo history across reload and platform-specific GPU performance are tracked separately.
