# NOIRADIX Studio — Keyboard Shortcuts

| Shortcut | Scope | Action |
| :--- | :--- | :--- |
| `B` / `P` | Cell Editor | Select Pencil (Pen) Tool |
| `E` | Cell Editor | Select Eraser Tool |
| `L` | Cell Editor | Select Line Tool |
| `R` | Cell Editor | Select Rectangle Tool |
| `G` | Cell Editor | Select Paint Bucket (Flood Fill) |
| `I` | Cell Editor | Select Eyedropper (Color Picker) |
| `M` | Cell Editor | Select Marquee Selection Tool |
| `Ctrl + Z` | Global | Undo last action / stroke |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Global | Redo last action |
| `Ctrl + S` | Global | Save `.pix2` file to disk |
| `Ctrl + O` | Global | Open `.pix2` file dialog |
| `Ctrl + N` | Global | New sprite sheet document |
| `Ctrl + C` | Cell / Grid | Copy current frame or floating selection |
| `Ctrl + X` | Cell Editor | Cut floating selection |
| `Ctrl + V` | Cell / Grid | Paste clipboard frame or floating selection |
| `Ctrl + A` | Cell Editor | Select all pixels in active cell |
| `Esc` | Cell Editor | Deselect marquee selection |
| `Delete` / `Backspace` | Cell Editor | Clear pixels in active selection |
| `Space + Drag` | Canvas | Pan viewport |
| `Mouse Wheel` | Canvas | Zoom in / Zoom out |
