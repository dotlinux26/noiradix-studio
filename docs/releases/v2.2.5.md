# NOIRADIX Studio & PixelArt v2.2.5

## Editing

- Add a separate selection tool across visible, unlocked source regions in both editors. Move, scale, rotate, flip, recolor and delete retain each pixel's region ownership. Isolation restricts the eligible subtree. Alignment applies one shared offset to the selected painted union.
- Add painted-pixel free selection. Drag over existing nontransparent pixels; hold Ctrl/Cmd across strokes and release it to finalize. Empty pixels are excluded, and the resulting mask supports ordinary selection operations.
- Preserve source region IDs when pasting back into the same project/frame after Undo/Redo. Layered paste into another PIX2 1.1 frame or project copies the hierarchy with unique IDs. Flat raster clipboard behavior remains available.
- Add explicit document conversion between PIX2 1.0 and 1.1. Flattening warns before discarding layers, groups, regions and their structural metadata. Undo/Redo is supported.

## Fixes

- Grid Overview paste, duplicate, row duplicate, flip and clear now update structural source data instead of only the derived composite cache. Saved changes survive reopening.
- Keep source ownership links consistent when Grid frame IDs or row/column coordinates change. Frame name and direction edits participate in Undo.
- Cancel a pending PixelArt source parse when Apply runs, preventing a delayed parse from replacing a document during a subsequent canvas operation.
- Restore the editor size alias after flattening and use each frame's individual size when compositing, avoiding render errors and clipping larger frames.
- Accept the full hit area of PixelArt selection resize handles at canvas edges.
- Synchronize both app version labels and runtime cache keys to 2.2.5.

## Compatibility and boundaries

- PIX2 remains version 1.1. No grammar or new format directive is introduced; PIX2 1.0 read compatibility remains.
- Selection masks, isolation and transform previews are transient editor state and are not serialized as artwork directives.
- Grid whole-frame commands operate on the complete hierarchy. All-layer selection excludes hidden/locked ancestors. See the [selection contract](../SELECTION_AND_CONTEXT_MENU.md) and [implementation report](../discussion/GRID_SELECTION_WORK_IN_PROGRESS.md).
- Flattening preserves the visible composite, not the editable hierarchy. Arbitrary-angle rotation and downscaling can lose samples under nearest-neighbor raster sampling.
- Save/reopen regressions use a simulated file handle for the Grid fixture. They verify file content and app lifecycle, not manual OS-picker interaction. Existing native-handle adapter suites remain enabled.
