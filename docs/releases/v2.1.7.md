# NOIRADIX Studio & PixelArt v2.1.7

Stable maintenance release. PIX2 remains version 1.1, with PIX2 1.0 read compatibility.

## Highlights

- Restored the original PIX2 and AI authoring demo alongside the Unity 2D export/import demo.
- Added distinct links for both demos to the Studio About dialog, root README, and documentation portal.
- Updated app version displays, cache-busting references, current product specifications, tests, and the README version badge to 2.1.7.

## Compatibility and limitations

- No PIX2 grammar, serialization, storage, or compatibility changes.
- Both demo links are external YouTube destinations; NOIRADIX remains usable offline apart from external links.
