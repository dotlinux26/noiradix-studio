# NOIRADIX Studio & PixelArt v2.2.4

## Highlights

- Completes the lightweight Studio PIX2 source preview styling: long source is collapsed by default, plain text stays readable in both themes, and the preview avoids the previous per-token DOM tree.
- Constrains directory listing badges in the About panel to a consistent compact height while preserving their aspect ratio.

## Compatibility

- Studio and PixelArt report version 2.2.4. PIX2 remains at version 1.1, with PIX2 1.0 read compatibility retained.
- This release does not change the PIX2 grammar or serialized artwork format.

## Limits

- The source-preview change reduces DOM and layout work. It does not change per-project undo history storage or guarantee a fixed total browser memory footprint.
- Expanding a long preview still creates a text node containing the full source; Edit mode also loads the full source into the textarea on demand.
