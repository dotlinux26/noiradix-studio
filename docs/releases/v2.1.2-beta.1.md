# v2.1.2-beta.1

Review beta on `rc2`; PIX2 remains 1.1 with 1.0 read compatibility.

- Shared queued native file writes preserve the originating tab, handle and unsaved edits.
- Quoted strings round-trip; resource profiles and bounded raster/import/export allocations are enforced.
- Studio demo/native opening use ordinary independent sessions; duplicate filenames remain distinct.
- Browser recovery ignores malformed catalogs; PixelArt saves preserve grid metadata.
- Export preview reuses its raster for zoom and rejects oversized output.
- CI covers all 19 Node suites and three browser runners, with independent branch queues.

Validation and remaining platform/interaction coverage: [RC2 audit](../discussion/RC2_AUDIT.md). This prerelease does not close every historical UX request and does not deploy or merge RC2 into main.
