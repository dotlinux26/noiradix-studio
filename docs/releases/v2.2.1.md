# NOIRADIX Studio & PixelArt v2.2.1

## Highlights

- The floating Animation Studio preview now opens in Fit mode and recalculates its fit when the preview area changes size. Fixed zoom choices remain available.
- Direction controls now cycle through clips tagged for the chosen direction in document order, wrapping to the first matching clip. Directions without tagged clips retain the legacy row-based fallback.
- The animation selector follows direction-driven playback and exposes an Auto by direction option.
- The bilingual Stable notice now appears on first visit across hosted and local-file modes, explains that Stable does not mean every area has been reviewed, and invites reproducible bug reports. Dismissal is remembered for three hours; the notice sits above canvas interactions and below dialogs.
- Added focused browser coverage for animation preview fitting, direction clip cycling, and first-visit banner behavior in Studio and PixelArt.
- Added English discussion records for the stable notice behavior, the reviewed 8-direction bat artifact, and shared editor interaction decisions.

## Compatibility

- Studio and PixelArt report version 2.2.1. PIX2 remains at version 1.1, with PIX2 1.0 read compatibility retained.
- This release does not change the PIX2 grammar or serialized artwork format.

## Limits

- Fit is calculated from the available preview viewport; it does not alter frame dimensions or artwork data.
- Clip cycling requires a direction tag and valid frame references. Untagged legacy projects continue using row-based playback when no matching tagged clip exists.
- The three-hour notice interval is its configured repeat delay; release checks verify dismissal persistence and copy, not elapsed wall-clock behavior.
