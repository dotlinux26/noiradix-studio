# NOIRADIX Studio & PixelArt v2.2.8

## Grid Overview & Animation Enhancements

- **Grid Overview Frame Swap**: Added desktop-grade frame swapping in the Grid Overview. Users can `Ctrl`+click (or `Cmd`+click) two frames to multi-select them (displaying high-contrast circular badges `1` and `2` with bright selection outlines), then right-click to choose "Swap Frames" from the context menu. Flawlessly exchanges artwork contents across both PIX2 1.1 (re-binding nested layer/region AST hierarchies to destination cell slots) and PIX2 1.0 (raster pixels), syncs composite layers, updates undo/redo history, and autosaves.
- **Row-level Tag & Animation Synchronization**: Setting a direction tag (`#grid-cell-dir` or `#cell-dir-select`) on any frame automatically synchronizes all frames in that entire row. Assigning an animation state in the Cell Editor assigns the entire row. In Slices & Tagging, editing a slice tag automatically updates all sibling slices in the same row.
- **Preview Directional Clip Cycling**: In the floating Animation Studio preview and platformer modes, repeatedly clicking directional compass buttons (or clicking while playing) cycles sequentially through all animation clips tagged with or matching that direction (e.g. `walk_right` → `run_right` → `attack_right`), updating the animation selector and displaying a toast notification.
- **UI & Layout Spacing Polish**: Separated the "Convert document to PIX2 1.0 / 1.1" action button below the layer tree with dedicated margin and full-width pill styling to avoid crowding against tree elements. Clarified the cross-layer selection tool (`fa-solid fa-object-group`).
- **Complete Version & Badge Consistency**: Synchronized all version badges, meta tags, and asset caches (`index.html`, `pixelart/index.html`, `js/version.js`) to v2.2.8, backed by comprehensive automated test assertions.
