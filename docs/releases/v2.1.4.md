# NOIRADIX Studio & PixelArt 2.1.4

Stable maintenance release. PIX2 remains version 1.1, with PIX2 1.0 read compatibility.

## Highlights

- Updated the Studio and PixelArt Discord community links to the current invite.
- Added a Linux and macOS launcher for downloading and running the browser app locally with Python 3.
- Updated product and Unity export descriptions to state that the Unity importer creates sprite assets and native `.anim` clips; Animator Controller setup remains in Unity.
- Refreshed README and product metadata for the current SourceForge listing and supported workflow.
- Updated visible app versions, cache-busting references, and release documentation to 2.1.4.

## Compatibility and limitations

- No PIX2 grammar, serialization, storage, or compatibility changes. PIX2 1.0 read compatibility remains supported.
- The Linux/macOS launcher requires Python 3 and a desktop browser opener (`open` on macOS or `xdg-open` on Linux). It binds the local server to `127.0.0.1` and stops when the launcher is interrupted.
- The local app is client-side; external links and optional third-party services still require an internet connection.
