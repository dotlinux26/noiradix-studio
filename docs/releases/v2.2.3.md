# NOIRADIX Studio & PixelArt v2.2.3

## Highlights

- Replaced the Studio read-only PIX2 syntax-highlighted view with a plain-text source preview to avoid constructing hundreds of thousands of DOM elements for large projects.
- Long source previews (over 24,000 characters) start collapsed and render their text only when expanded; collapsing releases the rendered text. Explicit Edit still loads the full canonical PIX2 source, and copy actions remain available independently.
- Added browser coverage for the large-source preview, expansion/collapse lifecycle, and full-source editing.

## Compatibility

- Studio and PixelArt report version 2.2.3. PIX2 remains at version 1.1, with PIX2 1.0 read compatibility retained.
- This release does not change the PIX2 grammar or serialized artwork format.

## Limits

- This change reduces DOM and layout work in the Studio read-only code view. It does not change per-project undo history storage or guarantee a fixed total browser memory footprint.
- Expanding a long preview still creates a text node containing the full source; Edit mode also loads the full source into the textarea on demand.
