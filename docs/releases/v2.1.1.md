# NOIRADIX Studio & PixelArt 2.1.1

This patch release introduces the official Arch-Lich Grim Reaper 48×48 reference template, provides resilient automated browser test harness execution in CI environments, documents AI cognitive model feedback, and aligns version manifests across the platform.

### Highlights
- **Arch-Lich Grim Reaper 48×48 Template**: Integrates the production-grade 4×4 boss sprite matrix authored under PIX2 1.1 with multi-layer Scene Graph hierarchy (`@layer aura`, `@group cloak`, `@region robe`, `@region skull`, `@layer weapon`), directional walk cycles (down, up, right, left), and 29-color spectral palette.
- **Reference Template Chooser**: Quick-start modal dialog for switching between the micro Noiradix Ghost (16×16) and macro Arch-Lich Reaper (48×48) templates directly from the toolbar or empty workspace state.
- **AI Argon 4.0 Parser Compatibility (RFC-PARSER-01 & RFC-PARSER-02)**: Resolves dimension delimiter compatibility in `rect` commands (supporting both `WxH` and `W,H`), and hardens inline comment lexing in `@palette` so comments (using `#` or `;`) and hex-like comment words are cleanly isolated without throwing invalid coordinate or hex color diagnostics.
- **AI Cognitive Feedback Documentation**: Records Gemini Argon 4.0 analysis of scanline rasterization vs. shape fills and inline palette comments in [`docs/ENGINEERING/AI_ARGON_PARSER_FEEDBACK_REPORT.md`](../ENGINEERING/AI_ARGON_PARSER_FEEDBACK_REPORT.md) and [`docs/ENGINEERING/KNOWN_LIMITATIONS.md`](../ENGINEERING/KNOWN_LIMITATIONS.md).
- **CI Test Harness Hardening**: Hardens Playwright browser testing with robust executable resolution fallback and dynamic timeout thresholds tailored for multi-core CI virtual machines.
