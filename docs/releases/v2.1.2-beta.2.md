# v2.1.2-beta.2 — Shared editor refactor

Review prerelease on `rc2`. PIX2 remains 1.1 with 1.0 read compatibility. Main and the production website are unchanged by this release.

- Studio grid, slicing, animation, source/AI and export are separated into feature controllers with explicit app ports.
- Palette data/library, raster mutation and floating selection settlement are shared by Studio and PixelArt.
- Selection cancellation retains original document/node ownership. Flips, quarter-turn and cumulative free rotation share source sampling.
- No-op history keeps redo; Studio Apply Code and external reload retain undoable history.
- Validated source publication prevents partial invalid documents from replacing artwork. Failed PixelArt reload restores the code view.
- Export metadata/per-frame source remain stable across asynchronous PNG encoding.
- CI discovers every Node and browser regression suite; architecture, history, file lifecycle and agent verification docs reflect the implementation.

Phase-by-phase decisions, findings and evidence: [refactor report](../discussion/EDITOR_REFACTOR_PROGRESS.md). This beta retains app-specific history/viewport/autosave wiring and existing paste presentation. Manual OS pickers, other browser engines and long-duration stress remain additional coverage; it is not an exhaustive closure of every historical product request.
