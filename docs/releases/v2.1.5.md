# NOIRADIX Studio & PixelArt v2.1.5

Stable maintenance release. PIX2 remains version 1.1, with PIX2 1.0 read compatibility.

## Highlights

- Added a PixelArt **Import PIX2** action that validates pasted source and opens it in a separate artwork tab.
- Added the official TeaserTrack and AlternativeTo listing badges and updated listing references in the product documentation.
- Corrected the Unity 2D demo link and clarified that Unity sprite slicing and animation creation use the exported `.pix2.json` metadata and importer.
- Changed the maintenance notice recheck interval from 30 minutes to 3 hours.
- Improved the PixelArt About dialog metadata contrast in light and dark themes.
- Updated both app version displays, cache-busting references, and product specification versions to 2.1.5.

## Compatibility and limitations

- No PIX2 grammar, serialization, storage, or compatibility changes. PIX2 1.0 read compatibility remains supported.
- The PIX2 paste-import action relies on the shared parser and PixelArt validation profile. Invalid input is rejected without replacing existing artwork tabs.
- Browser visual/interaction checks were skipped at the user's request for this release checkpoint. See [the implementation discussion](../discussion/PIXELART_IMPORT_AND_LISTING_UPDATES.md) for the specific unverified browser cases.
