# NOIRADIX Studio & PixelArt v2.1.8

## Highlights

- Moved the four approved directory links (SourceForge, VibeCodePicks, TeaserTrack and AlternativeTo) directly below the README verdict, with the official VibeCodePicks badge and existing official badges.
- Added the VibeCodePicks listing badge and SourceForge project link to the Studio About dialog and documented the directory listings in the documentation portal.
- Replaced stale, keyword-stuffed Studio metadata with concise descriptions of verified product capabilities; removed the unsupported `meta keywords` list.
- Updated Studio structured data to version 2.1.8 and added the canonical listing references.
- Added canonical and social preview metadata for PixelArt and added its URL to the sitemap.

## Compatibility and format

- Both applications report version 2.1.8.
- No PIX2 syntax, parsing, serialization, import, export or artwork behavior changed. PIX2 remains version 1.1.

- `node tests/run-all.cjs --syntax` — passed (35 production JavaScript files).
- `node tests/run-all.cjs` — passed (20 Node suites).
- `node tests/benchmark-performance.js` — passed all performance gates.
- `node tests/run-all.cjs --browser` — passed all 3 browser suites in Chrome for Studio and PixelArt.
- `git diff --check` — passed.
- GitHub Actions tag workflow — passed, and the stable v2.1.8 GitHub release was published.

## Limitations

- Directory badges link to the listings but cannot ensure that external sites provide followed inbound links or improve search rankings.
- Google does not use the `meta keywords` tag for ranking; this release removes it rather than maintaining a keyword list.
