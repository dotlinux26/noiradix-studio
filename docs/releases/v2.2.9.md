# NOIRADIX Studio & PixelArt v2.2.9

A quality-of-life and stability release resolving selection preservation, freehand mask illumination, and header resolution interactions across NOIRADIX Studio and PixelArt.

## Key Changes

- **Active Cell Resolution Widget & Frame Resize Hook**: Replaced multi-button Cell Res bar with a unified active resolution pill widget (`#btn-header-cell-res`) that automatically reflects the working tab or active cell dimensions (`W×H`) and seamlessly opens the Frame Resize modal when clicked.
- **Grid Overview Selection Preservation & Frame Swap Context Menu**: Fixed event double-invocation (`pointerdown` vs `click`) on `dom.gridCanvas` that previously deselected frames upon mouseup. Multi-frame selections (up to 2 cells) are now strictly preserved when right-clicking cells or canvas background, ensuring the "Swap Frames" context menu action remains reliably accessible.
- **Freehand Selection Mask Glow Persistence**: Resolved issue where illuminated purple selection glow disappeared when holding `Ctrl`/`Cmd` and releasing mouse without drawing. `EditorMultiSelection.drawMask` now natively handles both Set objects and function/getter references, while `state.selection` bounds remain synchronized throughout additive stroke intervals.
- **Complete Test & Manifest Synchronization**: Synchronized all versions, badges, and automated test assertions across 24 Node test suites and 10 browser verification suites.
