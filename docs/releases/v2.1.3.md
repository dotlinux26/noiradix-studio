# NOIRADIX Studio & PixelArt 2.1.3

Stable maintenance release. PIX2 remains version 1.1, with PIX2 1.0 read compatibility.

## Highlights

- Unity 2021.1 and newer use the Sprite Data Provider API for atlas slicing metadata; Unity 2021.2 and newer also register sprite name/file-ID pairs.
- Older Unity versions retain a compile-time fallback using `TextureImporter.spritesheet`.
- Reimports preserve sprite IDs for unchanged frame names, and generated animation asset paths use Unity's forward-slash convention.
- Fixed the generated importer completion string so exported C# compiles instead of containing literal line breaks inside a string.

## Compatibility and limitations

- No PIX2 grammar, serialization or storage format change. PIX2 1.0 read compatibility remains supported.
- The legacy branch intentionally uses Unity's obsolete sprite-sheet API to support older editor versions.
- The repository environment has no Unity Editor, so compiling and exercising the modern and legacy branches inside their target Unity versions remains an external integration check.

## Verification

Local syntax and Node suite results are recorded with the release workflow. GitHub Actions runs syntax, all Node suites, performance benchmarks and browser tests before publishing this tag. See [the Unity importer compatibility note](../discussion/UNITY_IMPORTER_REGRESSION.md).
