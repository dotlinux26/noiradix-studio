# NOIRADIX Studio & PixelArt v2.2.7

## Selection & Tooling Refinements

- **Persistent Selection Glow on Release**: Freehand selection now keeps its vivid indigo/violet illumination (`rgba(99, 102, 241, 0.45)` with `#a5b4fc` inner stroke) permanently visible upon releasing the mouse, clearly marking the selected pixels until deliberately dismissed or modified.
- **Additive Free Selection**: Clicking or brushing with `Ctrl`/`Cmd`/`Shift` held now seamlessly accumulates onto the existing selection mask rather than resetting or flashing away.
- **Zero-Jitter Smooth Move Dragging**: Fixed coordinate drift and jumpy dragging when moving selections. Coordinates in the selection mask are translated dynamically via `EditorMultiSelection.translateMask(mask, dx, dy)`, and baseline offsets update on mouseup to eliminate snap-back glitches.
- **No Unsolicited Tool Mode Switching**: Finished freehand selection gestures stay in `free-select` mode without forcing the active tool back to rectangular `select`.
- **Select Across Layers Disambiguation**: Updated toolbar icon from `fa-solid fa-layer-group` to `fa-solid fa-object-group`, clarifying its function as cross-layer/multi-object grouping selection distinct from the Structure & Layers panel toggle.
- **Convert to PIX2 1.0 Button Spacing**: Added top margin (12px) and bottom margin (8px) below the layer tree for the format downgrade button to prevent crowding against layer elements.
