# NOIRADIX Studio & PixelArt 2.1.2

Stable release. PIX2 remains version 1.1, with PIX2 1.0 read compatibility.

## Highlights

- Studio and PixelArt share the raster mutation, palette, floating-selection and transform foundations delivered in the 2.1.2 beta cycle, while retaining app-specific viewport, history and persistence adapters.
- Studio feature controllers for grid, slicing, animation, source/AI and export use explicit app ports.
- Native file writes, recovery, project tabs, source publication and asynchronous export handling received hardening during the beta cycle.
- Added the Arch-Lich Grim Reaper and Cute Cat PIX2 sample projects.
- Fixed the generated Unity importer completion dialog: escaped newlines now remain inside the C# string instead of breaking the generated script across lines and preventing Unity compilation.

## Compatibility and limitations

- No PIX2 grammar, serialization or storage format change. PIX2 1.0 read compatibility remains supported.
- The Unity importer correction was checked in the generated-script template and repository release gates. A Unity Editor compiler is not available in this repository environment, so compilation in a real Unity project remains an external integration check.
- The shared editor architecture still preserves app-specific history, viewport and autosave wiring. The release does not claim closure of every historical UX request.
