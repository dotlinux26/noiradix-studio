# NOIRADIX Studio & PixelArt v2.2.2

## Highlights

- Header file name widget and status bar path pill now synchronize immediately on save across NOIRADIX Studio and PixelArt without requiring a manual page reload.
- Saving or Save-As with a new disk file handle or file name updates the active project session metadata, document title, header rename input, and project tab strip simultaneously.
- Opening an external file via OS file picker or handle synchronizes the header title input directly with the opened file's disk name.

## Compatibility

- Studio and PixelArt report version 2.2.2. PIX2 remains at version 1.1, with PIX2 1.0 read compatibility retained.
- This release does not change the PIX2 grammar or serialized artwork format.
